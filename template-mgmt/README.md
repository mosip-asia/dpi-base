## 🏛️ Architecture Overview

The Sovereign Domain management plane is designed to be:
* **100% Stateless & GitOps Managed**: All infrastructure state is defined declaratively in Terraform and version-controlled.
* **Cost-Efficient**: Operates at ~$0.20/month base cost (covering only authoritative Cloud DNS records and GCS state storage).
* **Decoupled & Sovereign**: Owns its own GCS remote state bucket (`gs://__STATE_BUCKET__`), Cloud DNS subzone (`__SUBDOMAIN__`), and Secret Manager vault.
* **Zero Blast Radius**: Workload projects under this domain declare project containers in `prj-*.tf` envelopes without impacting the base platform or other sovereign domains.

## 🚀 Quick Deployment Guide

1. **Verify `terraform.tfvars`**:
   Ensure `terraform.tfvars` is present (automatically generated by `scripts/bootstrap_domain.sh`).

2. **Initialize Terraform Backend**:
   ```bash
   cd terraform
   terraform init
   ```

3. **Deploy Management Plane**:
   ```bash
   terraform plan
   terraform apply
   ```

4. **Complete DNS Delegation Handshake**:
   Capture the assigned nameservers from `terraform output name_servers` and add them as an NS record in parent zone `dpi-center` (`ait-brainlab-mgmt`). See `docs/sop-domain-mgmt.md` for complete runbook.
